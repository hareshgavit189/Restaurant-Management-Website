# 🍽️ Restaurant Management Website

A visually attractive Restaurant Management Website developed using HTML and CSS. The project focuses on converting a static HTML website into a well-designed and visually consistent restaurant website using external CSS.

## 🎯 Objective

The objective of this project is to style a static HTML restaurant website using External CSS and improve its overall appearance, layout, and visual consistency.


✨ Features

🎨 External CSS styling

🧭 Attractive navigation menu

🍔 Food cards for displaying menu items

🖼️ Image gallery

🎨 Custom colors and backgrounds

✍️ Improved typography and fonts

📏 Proper margins and padding

🔲 Borders and visual effects

🔄 Consistent design throughout the website

## 🛠️ Technologies Used

HTML5 – For creating the structure and content of the website

CSS3 – For styling and improving the visual appearance

## 📚 Concepts Covered

This project demonstrates the following CSS concepts:

CSS Selectors

Fonts and Typography

Colors

Margins

Padding

Borders

Backgrounds

External CSS

Navigation Menu Styling

Food Card Design

Image Gallery Styling

## 📂 Project Structure
Restaurant-Management-Website/
│
├── index.html
├── style.css

File Description

index.html – Contains all the website content and sections, including the navigation menu, food menu, about section, contact section, and image gallery.

style.css – Contains all external CSS styles used to design and format the website.

README.md – Provides information about the project.

## 🚀 How to Run

Download or clone this repository.

Open the project folder.

Open index.html in a web browser.

Explore the restaurant website.

No additional software or installation is required.
